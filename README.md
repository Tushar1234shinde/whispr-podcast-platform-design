# Whispr Podcast Platform

A React and Vite prototype for discovering podcasts and connecting with creators.

## Getting started

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Pages

The app uses hash-based routes:

- `#/` — Home
- `#/discover` — Podcast discovery
- `#/podcast` — Podcast details
- `#/login` and `#/signup` — Authentication screens
- `#/dashboard` — Listener dashboard
- `#/creator` — Creator page

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
